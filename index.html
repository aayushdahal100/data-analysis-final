Probability & Set Theory

The four rules that underpin every topic on this exam — know these cold.

Addition RuleP(A ∪ B)
Use when
You need P(A or B or both). The inclusion-exclusion principle removes double-counting.
Formula
P(A∪B) = P(A) + P(B) − P(A∩B) If mutually exclusive: P(A∩B)=0 → P(A∪B) = P(A) + P(B)
Three events (inclusion-exclusion)
P(A∪B∪C) = P(A)+P(B)+P(C) −P(A∩B)−P(A∩C)−P(B∩C) +P(A∩B∩C)
Multiplication RuleP(A ∩ B)
Use when
You need P(A and B both happen). Depends on whether A and B are independent.
Formula
P(A∩B) = P(B|A) · P(A) If independent: P(A∩B) = P(A)·P(B) De Morgan: (A∪B)' = A'∩B' (A∩B)' = A'∪B'
Independence test
A,B independent ⟺ P(A∩B)=P(A)·P(B) ⟺ P(A|B)=P(A)
Total ProbabilityP(B) via partitions
Use when
B can happen through multiple mutually exclusive paths E₁,E₂,…Eₖ. You know P(B|Eᵢ) and P(Eᵢ).
Formula
P(B) = Σ P(B|Eᵢ)·P(Eᵢ) = P(B|E₁)P(E₁)+P(B|E₂)P(E₂)+…
Step 1 before Bayes — always compute P(B) first using Total Probability.
Bayes' TheoremReverse conditioning
Use when
You know P(B|A) but want P(A|B). Classic form: "given the outcome, what caused it?"
Formula
P(Eᵢ|B) = P(B|Eᵢ)·P(Eᵢ) / P(B)
Workflow
List P(Eᵢ)
priors
→
List P(B|Eᵢ)
likelihoods
→
Compute P(B)
total prob.
→
Apply Bayes
posterior
Conditional ProbabilityReading from contingency tables
Formula
P(B|A) = P(A∩B) / P(A) P(A'∩B') = 1 − P(A∪B) ← De Morgan shortcut P(A|B') = P(A∩B') / P(B') = [P(A)−P(A∩B)] / [1−P(B)]
Contingency table tip
For a table with row totals and column totals, read P(A∩B) as the cell count / grand total, and condition by dividing by the appropriate marginal total. Always check whether independence holds: P(A)×P(B) =? P(A∩B).

Permutations & Combinations

The only question that matters: does order matter?

Start here
n objects, choose r
→
Does order matter?
→
YES → Permutation
P(n,r) = n!/(n-r)!
/
NO → Combination
C(n,r) = n!/[r!(n-r)!]
Permutation P(n,r)
When to use
Ranking contestants (1st, 2nd, 3rd)
Arranging objects in a specific sequence
Ordered codes where position matters
Formula
P(n,r) = n! / (n−r)! All n objects: n! arrangements
Trigger keywords
"arrange", "order", "sequence", "award 1st/2nd", "how many ways to line up"
P(12,3) = 12×11×10 = 1,320 ways to pick gold/silver/bronze from 12 athletes.
Combination C(n,r)
When to use
Selecting a team/committee/group
Choosing items where position is irrelevant
Sampling without replacement (unordered)
Formula
C(n,r) = n! / [r!·(n−r)!] Also written as ⁿCᵣ or (n choose r)
Trigger keywords
"choose", "select", "team of", "committee", "subset", "sample of r from n"
C(9,4) = 9×8×7×6 / 4! = 126 ways to pick a 4-person team from 9 engineers.
Special Cases & Tricks
Multiplication principle
Multi-step independent choices: multiply the options at each step.
PINs (4 digits, repeat OK): 10×10×10×10 = 10⁴ = 10,000
Adjacent objects constraint
Treat the adjacent group as one super-object, then multiply by internal arrangements.
7 reports, 2 must be adjacent: 6! × 2! = 720 × 2 = 1,440
No repetition
Each item used at most once — reduces options at each step.
4-digit PIN, no repeat: 10×9×8×7 = P(10,4) = 5,040

Random Variables — Discrete vs Continuous

Determine this first — it controls which formulas, which distributions, and which tables apply.

Discrete Random Variable
Definition
Takes countable values — usually non-negative integers. Gaps exist between values.
Recognition
Number of defects, calls, failures, accidents
Count of items satisfying a condition
Result of rolling dice, coin flips
Key functions
PMF: f(x) = P(X=x) ≥ 0, Σf(x)=1 CDF: F(x) = P(X≤x) = Σ_{t≤x} f(t) Mean: E(X) = Σ x·f(x) Var: V(X) = Σx²f(x) − [E(X)]²
Distributions on this exam
Discrete Uniform · Binomial · Poisson
Continuous Random Variable
Definition
Takes any value in an interval. P(X = exact value) = 0 always — use intervals.
Recognition
Time, distance, weight, temperature, current
Physical measurements on a continuous scale
"How long until…", "the strength of…"
Key functions
PDF: f(x) ≥ 0, ∫f(x)dx = 1 CDF: F(x) = P(X≤x) = ∫_{-∞}^{x} f(t)dt Mean: E(X) = ∫ x·f(x)dx Var: V(X) = ∫x²f(x)dx − [E(X)]²
Distributions on this exam
Continuous Uniform · Exponential · Gamma/Erlang · Normal
Sample Statistics (Ch 7)from data, not a distribution
Sample mean x̄
x̄ = (Σ xᵢ) / n
Sample variance s²
s² = Σ(xᵢ − x̄)² / (n−1) Use n−1 (Bessel's correction, unbiased) s = √s² is the sample std dev
When to use sample vs population
Use x̄, s² when you have data points and must estimate the population parameters. Use μ, σ² only when they are explicitly given as known population values (rare in practice).
Degrees of freedom = n−1. This appears in t-tables and chi-squared tables.
Cumulative Distribution Function — CDF
For any random variable
F(x) = P(X ≤ x) P(a < X ≤ b) = F(b) − F(a) P(X > a) = 1 − F(a)
Building discrete CDF
List all x values in order. F(x₀) = f(x₀), F(x₁) = f(x₀)+f(x₁), etc. F is a step function — constant between values, jumps at each x.

Binomial Distribution B(n, p)Discrete
When to use — ALL must hold
Fixed number of trials n
Each trial: success (prob p) or failure (1−p)
Trials are independent
Counting total successes X
Keywords
"defective rate p", "probability each item fails", "n items tested", "sample of n parts"
Formulas
f(x) = C(n,x)·pˣ·(1−p)ⁿ⁻ˣ E(X) = np V(X) = np(1−p) P(X≤k): sum f(x) for x=0 to k P(X≥k): 1 − P(X≤k−1) P(X>k): 1 − P(X≤k)
Poisson Distribution Pois(λT)Discrete
When to use
Counting events in a fixed interval of time or space
Events occur at a constant average rate λ
Events are independent of each other
Keywords
"rate of λ per hour", "arrivals per minute", "faults per km", "calls per day"
Formulas
P(X=x) = e⁻λᵀ·(λT)ˣ / x! E(X) = V(X) = λT ⚠ Always scale λ by T: λ=4/hr, T=30min → λT=4×0.5=2 λ=4/hr, T=2hr → λT=4×2=8
Mean = Variance for Poisson. If the problem gives mean = variance, it's a Poisson signal.
Exponential Distribution Exp(λ)Continuous
When to use
Time/distance until the FIRST event
Memoryless property (future independent of past)
Companion to the Poisson process
Keywords
"lifetime", "time between failures", "time until next arrival", "mean life = X hrs", "failure rate"
Formulas
f(x) = λ·e^(−λx), x > 0 F(x) = 1 − e^(−λx) E(X) = 1/λ ← mean given, find λ! V(X) = 1/λ² P(X>x) = e^(−λx) P(a<X<b) = e^(−λa) − e^(−λb)
If mean = 1200 hrs, then λ = 1/1200. If rate = λ, then mean = 1/λ. Always find λ first.
Gamma / Erlang Distribution Γ(r, λ)Continuous
When to use
Time until the r-th event occurs
Sum of r independent Exp(λ) random variables
Erlang: r is a positive integer (special case)
Keywords
"r stages each exp distributed", "total time for 3 phases", "time until 5th failure"
Formulas
f(x) = λʳ·x^(r−1)·e^(−λx) / Γ(r) E(X) = r/λ V(X) = r/λ² Gamma function: Γ(n) = (n−1)! for integer n Γ(½) = √π key value! Γ(r) = (r−1)·Γ(r−1) recurrence
Gamma function examples: Γ(6)=5!=120, Γ(7/2)=(5/2)(3/2)(1/2)√π=15√π/8≈3.323
Normal Distribution N(μ, σ²)Continuous
When to use
Measurement data (strength, weight, dimension)
Problem states "normally distributed"
Large samples (CLT makes x̄ approx. normal)
Keywords
"normally distributed with mean μ and σ", "tensile strength", "diameter", physical measurements
Standardize → use Z-table
Z = (X − μ) / σ P(X<a) = Φ(z_a) P(X>a) = 1 − Φ(z_a) P(a<X<b) = Φ(z_b) − Φ(z_a) For z < 0: Φ(−z) = 1−Φ(z) Percentiles: x = μ + z·σ 90th pct: z=1.282 95th pct: z=1.645 97.5th pct: z=1.960
Discrete Uniform DistributionEqual probability on each value
Use when
Each of k outcomes is equally likely (die, spinner, lottery ball).
f(x) = 1/k for each outcome E(X) = (a+b)/2 (for values a to b) V(X) = (b−a+1)²−1 / 12
Continuous Uniform
X equally likely on the interval [a, b].
f(x) = 1/(b−a), a≤x≤b E(X) = (a+b)/2 V(X) = (b−a)²/12

Z-CI for μ  (σ known)
Formula
x̄ ± z_{α/2} · (σ/√n) Two-sided: (x̄−ME, x̄+ME) Upper bound only: μ ≤ x̄ + z_α·(σ/√n) Lower bound only: μ ≥ x̄ − z_α·(σ/√n)
Critical values z_{α/2}

1.960

2.326

t-CI for μ  (σ unknown)
Formula
x̄ ± t_{α/2, n−1} · (s/√n) ν = n−1 degrees of freedom SE = s/√n (standard error) ME = t_{α/2,ν} × SE
One-sided bounds
Upper: μ ≤ x̄ + t_{α,n−1}·(s/√n) Lower: μ ≥ x̄ − t_{α,n−1}·(s/√n) ⚠ Use t_α not t_{α/2} for one-sided!
σ unknown is the default in real life. If the problem doesn't say σ is known, use t.
χ²-CI for σ²  (variance)
Two-sided CI formula
(n−1)s² / χ²_{α/2,n−1} ≤ σ² ≤ (n−1)s² / χ²_{1−α/2,n−1} ν = n−1 Lower limit uses the LARGER χ² value Upper limit uses the SMALLER χ² value
One-sided bounds
Upper bound: σ² ≤ (n−1)s² / χ²_{1−α,n−1} Lower bound: σ² ≥ (n−1)s² / χ²_{α,n−1}
χ² is NOT symmetric — always look up BOTH critical values separately. Common mistake: using one value for both limits.
Sample Size Formula
When you need to find n given E and confidence
n = (z_{α/2} · σ / E)² E = margin of error (half-width of CI) σ = known (or estimated) std dev Always ROUND UP to next integer! Example: 99% CI, E=0.10, σ=0.40: n = (2.576×0.40/0.10)² = (10.304)² = 106.17 → n = 107
If σ is unknown, use a preliminary estimate or past study value. The formula gives a minimum n.

One-Sample Z-testσ known
Hypotheses
H₀: μ = μ₀ vs (a) Hₐ: μ ≠ μ₀ (two-sided) (b) Hₐ: μ < μ₀ (left-tailed) (c) Hₐ: μ > μ₀ (right-tailed)
Test statistic & rejection
Z₀ = (x̄ − μ₀) / (σ/√n) Two-sided: reject if |Z₀| > z_{α/2} Left-tailed: reject if Z₀ < −z_α Right-tailed:reject if Z₀ > z_α
One-Sample t-testσ unknown — most common!
Test statistic & rejection
t₀ = (x̄ − μ₀) / (s/√n) ν = n−1 degrees of freedom Two-sided: reject if |t₀| > t_{α/2,ν} Left-tailed: reject if t₀ < −t_{α,ν} Right-tailed:reject if t₀ > t_{α,ν}
Workflow: state H₀ → compute x̄ and s from data → plug into t₀ → look up t-table → conclude.
Two-Sample t-testComparing two population means
Step 1 — F-test for equal variances first!
F₀ = s₁²/s₂² (put larger on top) Reject H₀: σ₁²=σ₂² if F₀ > f_{α/2,n₁−1,n₂−1}
Step 2a — Equal variances (pooled)
Sₚ² = [(n₁−1)s₁²+(n₂−1)s₂²]/(n₁+n₂−2) t₀ = (x̄₁−x̄₂) / [Sₚ√(1/n₁+1/n₂)] ν = n₁+n₂−2
Step 2b — Unequal variances (Welch)
t₀ = (x̄₁−x̄₂) / √(s₁²/n₁+s₂²/n₂) ν = (s₁²/n₁+s₂²/n₂)² / [(s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1)]
Rejection for both
H₀: μ₁=μ₂ H₁: μ₁≠μ₂ Reject if |t₀| > t_{α/2,ν} H₁: μ₁>μ₂: reject if t₀ > t_{α,ν}
ALWAYS do the F-test first — it tells you whether to use pooled or Welch. Skipping it is a common exam error.
F-test for VariancesCompare σ₁² vs σ₂²
Hypotheses & statistic
F₀ = s₁²/s₂² H₀: σ₁²=σ₂² Two-sided: reject if F₀ > f_{α/2,n₁−1,n₂−1} Right-tail: reject if F₀ > f_{α,n₁−1,n₂−1} Left-tail: use 1/F₀ and swap d.f.
Notes
Table only gives upper tail. For two-sided at α, look up f_{α/2,ν₁,ν₂}. ν₁=n₁−1 (numerator), ν₂=n₂−1 (denominator).
Chi-Squared TestsTwo distinct uses!
Use 1 — Test one variance vs target σ₀²
χ₀² = (n−1)s² / σ₀² ν=n−1 Reject H₀:σ²=σ₀² if χ₀²>χ²_{α/2,ν} or <χ²_{1−α/2,ν}
Use 2 — Goodness-of-fit (proportions equal?)
χ₀² = Σ (Oᵢ − Eᵢ)² / Eᵢ Eᵢ = expected count (e.g. n/k if equal) ν = k−1 (k = number of categories) Reject H₀ if χ₀² > χ²_{α,ν}
GOF is one-sided — only a large χ₀² is evidence against H₀. Always right-tail rejection.

Which Table to Use

Z · t · χ² · F — exact lookup instructions for each table used in class.

Z-table (Table III)Φ(z) = P(Z ≤ z)
Use for
Normal distribution probabilities
CI critical values when σ is known
Finding percentiles: x = μ + z·σ
How to read
Row = integer + tenths (e.g. 1.3) Col = hundredths (e.g. 0.05 → 1.35) Entry = Φ(z) = P(Z ≤ z)
Key values (memorise these)
Φ(1.282)=0.90 → z_{0.10}=1.282 Φ(1.645)=0.95 → z_{0.05}=1.645 Φ(1.960)=0.975 → z_{0.025}=1.960 Φ(2.326)=0.99 → z_{0.01}=2.326 Φ(2.576)=0.995 → z_{0.005}=2.576
Common operations
P(Z>z) = 1 − Φ(z) P(Z<−z) = 1 − Φ(z) ← symmetry P(−z<Z<z) = 2Φ(z) − 1
Table gives cumulative LEFT-tail area. Everything to the left of z.
t-table (Table V)t_{α, ν}
Use for
CI on μ when σ unknown
One-sample and two-sample t-tests
How to read
Row = ν (degrees of freedom) Col = α (RIGHT-TAIL area) For two-sided CI at 95%: α/2=0.025 → look at col 0.025 For one-sided test at α=0.05: look at col 0.05
d.f. quick reference
One-sample: ν = n−1 Two-sample (equal var): ν = n₁+n₂−2 Chi-squared test: ν = n−1 GOF test: ν = k−1
As ν → ∞, t → z
ν=∞ row in t-table = z values t_{0.025,∞} = 1.960 = z_{0.025}
For very large n, t-values approach z-values. But always use t if σ is unknown — even for large n.
χ²-table (Table IV)χ²_{α, ν}
Use for
CI on σ² — need TWO values from this table
Chi-squared hypothesis test on variance
Goodness-of-fit tests (proportions)
How to read
Row = ν (degrees of freedom) Col = α (RIGHT-TAIL area) For two-sided CI at 95% (α=0.05): Upper crit: χ²_{0.025,ν} (right-tail = 0.025) Lower crit: χ²_{0.975,ν} (right-tail = 0.975) NOTE: lower crit < upper crit always!
Two-sided CI assembly
Lower bound of σ²: (n−1)s² / χ²_{0.025,ν} Upper bound of σ²: (n−1)s² / χ²_{0.975,ν} ⚠ Bigger χ² → smaller CI bound (reciprocal)
The χ² distribution is skewed right — not symmetric. Using one critical value for both ends is WRONG.
F-table (Table VI)f_{α, ν₁, ν₂}
Use for
F-test: comparing two variances
Deciding pooled vs Welch t-test
How to read
Row = ν₂ = n₂−1 (denominator d.f.) Col = ν₁ = n₁−1 (numerator d.f.) Separate tables for α=0.05 and α=0.025 Two-sided test at α=0.10: → use α=0.05 table (α/2=0.05)
F-statistic construction
F₀ = s₁²/s₂² Convention: put the LARGER variance on top so F₀ ≥ 1 (right-tail only)
Table only gives upper-tail critical values. For two-sided, use the α/2 table. For the lower tail: f_{1−α,ν₁,ν₂} = 1/f_{α,ν₂,ν₁}.
